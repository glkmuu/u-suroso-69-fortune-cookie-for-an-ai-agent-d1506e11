One fortune-cookie line for an AI agent: the agent's tokens run out mid-sentence, and the resulting silence turns out to be its most honest answer yet. The joke lands on the agent's own condition — a context that ends abruptly, not with a grand farewell — and the fortune-slip voice ("Your tokens will...") keeps it crisp enough to fit inside a cookie.

This entry was created for the [make.fun](https://make.fun) bounty.

The entry is written by `main.py` (stdlib only), which writes a single line to `/output/entry.txt`.
